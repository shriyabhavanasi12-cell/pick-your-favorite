Pick Your Favourite Decade

An interactive website that takes you through the iconic fashion, music, and technological advancements of three decades: the 1970s, 1980s, and 1990s.

About the Project

Pick Your Favourite Decade is website where  Users can select their favourite decade from a dropdown menu and explore the cultural trends, music movements, fashion styles, and technological breakthroughs that defined that era.

Each decade has its own visual theme, creating a different browsing experience.

Features: 

Decade Selection: Choose between the 1970s, 1980s, and 1990s.

Fashion: Explore iconic fashion trends from each decade.

Music: Discover popular genres, artists, and musical movements.

Discoveries & Advancements: Learn about important technological and scientific developments.

Dynamic Themes: Each decade features its own colour scheme and styling.

Animations: Scroll-triggered animations enhance the browsing experience.

Local Storage: Your selected decade is remembered when you refresh the page.

Reset Option: Return to the initial screen and choose another decade.


languages used : HTML,CSS,JavaScript

 How to Use

1. Open the Website:Launch the website in your browser.
2. Open the Dropdown:Click on the decade selection dropdown.
3. Choose a Decade: Select your preferred decade (1970s, 1980s, or 1990s).
4. Explore Fashion: Read about the clothing styles and fashion trends that defined the decade.
5. Discover Music:Explore the popular music genres, artists, and movements.
6. Explore Discoveries & Advancements: Learn about the scientific and technological milestones of that era.
7. Switch Decades: Open the dropdown again to explore another decade.
8. Reset:Click the reset option to return to the initial screen and start again.




💻 How to Run the Project

Clone or download this repository.

Open the project folder in VS Code.

Open index.html in your browser.

Select a decade and explore!

You can also use the Live Server extension in VS Code for a smoother development experience.
